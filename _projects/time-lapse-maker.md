## About

Time-Lapse Maker is a Java desktop application for building time-lapse
videos. It assembles a sequence of photos into a video, making it easy to
turn periodic captures — a growing plant, a workshop in progress, a sky
changing over a day — into a smooth time-lapse.

The project is a Maven multi-module build, with dedicated packaging for
Linux, macOS and Windows so the tool can be used as a native desktop
application on each platform.

## What is here?

- Photo sequence → time-lapse video
- Java desktop application
- Per-platform packaging for Linux, macOS and Windows
- Maven multi-module project
