## About

Simple VTT is a lightweight, self-hosted virtual tabletop for tabletop
roleplaying games. It lets a game master prepare maps ahead of a session
and share them with players, who join remotely from their browser — no
installation needed, whether on desktop or tablet.

The app imports [Universal VTT](https://github.com/universal-vtt) (`.uvtt`)
map files, including their walls, doors, windows and multiple floors, so
maps prepared in other tools can be used directly. A "props" extension
also allows scenery such as trees and furniture to be placed from UVTT
bundles.

## What is here?

- Map preparation for the game master
- Browser-based access for connected players
- Universal VTT (`.uvtt`) import: walls, doors, windows, floors
- Props extension for scenery placement
- Self-hosted deployment with Docker and Apache (HTTPS / WebSockets)
