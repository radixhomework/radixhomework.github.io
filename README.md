# RadixHomeWork

A small Jekyll / GitHub Pages site for personal projects.

## Structure

- `index.md` — home page
- `about.md` — about page
- `_projects/` — individual projects
- `_layouts/` — page layouts
- `assets/css/style.scss` — RadixHomeWork theme
- `_config.yml` — Jekyll configuration

## Local preview

If Ruby and Bundler are installed:

```bash
bundle install
bundle exec jekyll serve
```

Then open the local address shown by Jekyll.

## GitHub Pages

Push the repository to GitHub and enable GitHub Pages from the repository settings.
The site can use GitHub Pages' built-in Jekyll build.
